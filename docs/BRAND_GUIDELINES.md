# Makoki Test - Brand Guidelines

## 🎯 Brand Positioning

### Vision

Become the reference extension for test data generation in Africa, celebrating the diversity and authenticity of African data.

### Mission

Provide African developers with an intelligent tool that generates relevant and familiar test data, thereby improving the quality and relevance of their tests.

### Values

- **Intelligence** (Makoki): Smart and adaptive solutions
- **Authenticity**: Truly representative data
- **Accessibility**: Simple, fast, free
- **Community**: Built by and for African devs

---

## 🎨 Visual Identity

### Logo

**Main Concept**: A stylized brain formed from African geometric patterns

- The brain represents "Makoki" (intelligence)
- Patterns evoke African heritage
- Modern and tech-friendly style

**Variations**:

- Full logo: Icon + "Makoki Test"
- Icon only: For small spaces
- Monochrome: For colored backgrounds

### Color Palette

```css
/* Primary Colors */
--makoki-emerald: #10b981; /* Intelligence, growth */
--makoki-orange: #f59e0b; /* Energy, African warmth */
--makoki-blue: #1e40af; /* Technology, trust */

/* Secondary Colors */
--makoki-purple: #7c3aed; /* Creativity */
--makoki-red: #dc2626; /* Alert, validation */

/* Neutrals */
--makoki-dark: #1f2937; /* Primary text */
--makoki-gray: #6b7280; /* Secondary text */
--makoki-light: #f9fafb; /* Backgrounds */
```

### Typography

- **Headings**: Inter or Poppins (modern, readable)
- **Body**: System fonts for performance
- **Code**: Fira Code or JetBrains Mono

## 📝 Tone and Voice

### Brand Personality

- **Intelligent** but not condescending
- **Professional** but accessible
- **African** and proud of it
- **Useful** above all

### Key Messages

1. "Test data that looks like you"
2. "Intelligent. Local. Instant."
3. "Makoki Test - Intelligence at the service of your tests"
4. "No more John Doe, welcome Amara Diallo"

### Communication Examples

❌ **Avoid**:

- "The most powerful testing tool"
- "Revolutionize your tests"
- Overly technical or elitist language

✅ **Prefer**:

- "Generate African test data in one click"
- "Names, addresses, and data that speak to your users"
- "Makoki Test understands your needs"
